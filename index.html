Generador de contraseñas

Comprobador de contraseñas filtradas

API de Have I Been Pwned con k-anonymity: solo se envían los 5 primeros caracteres del hash SHA-1.

Limpiador de metadatos

Re-exporta la imagen mediante canvas y elimina EXIF/GPS y la mayoría de metadatos. Solo imágenes.

Acortador de enlaces

Utiliza la API pública de is.gd. El enlace largo se envía a ese servicio. Para máxima privacidad usa un acortador autoalojado.

Compresor de imágenes
